# Migration from v86

v86 remains the visual fallback/reference. Web 2.0 is rebuilt instead of patching v86's intertwined renderer logic.

Phase 1: foundation + API + deterministic pattern contract.
Phase 2: realtime Binance stream through a dedicated market-data service.
Phase 3: order book, MTF, scanner, watchlist and backtest modules.
Phase 4: broader pattern library + walk-forward validation dataset.
Phase 5: optional AI context layer. AI may score context, but it does not invent a pattern.
